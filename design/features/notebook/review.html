The Notebook, with Notion's quality as the template

accepted (the person, 2026-11-20, after round 5) · 0 of 52 rows built

Decisions, 2026-11-21

  • Enter at the start of a non-empty block (the lead, 2026-11-21). Enter at the start of a non-empty block inserts an empty block above, caret stays with the text, like Notion. The file cannot hold an empty block, so the empty block is a line above that is written only when it is clicked and typed in; leaving it alone leaves the file as it was (test enter_at_start_adds_a_block_above).
  • The / menu after a space, NB3 (the lead, 2026-11-21). (1) / typed after a space opens the menu right there in the line: no new block, no extra Enter. The / is taken out of the line when a command is picked or Esc is pressed (or the menu is closed any other way); a picked block kind is inserted as a new block below, and the line keeps its text, like Notion (test slash_after_a_space_inserts_a_block_below; on an empty line a pick still writes its form in the line). (2) wb block add ID "REF" --scripture --after N writes the fenced scripture block holding only the reference (the reference is checked against the Bible); without --scripture a bare reference stays a paragraph. (3) Editing an existing scripture block uses the reference field of row 7, not the older "Edit card" form (test editing_a_scripture_block_uses_the_reference_field). The form stays for the other fenced blocks (view, thread, word), a question and a template's blank, which nothing else edits yet.
  • The @ chip in the file, NB5 (the person, 2026-11-21). The file keeps the plain reference text (e.g. Psalm 106:30). The chip is how the editor draws a reference it recognises, so every recognised reference in a block is drawn as a chip, whether it was placed with @ or typed; other Markdown tools show the words and the page index finds them as before. @ places a verse as its plain reference, and a page, a folder or Today as a [[link]]. While a block is being written its references are plain text; the chip shows when the block is left. The chip and the compact chapter panel are one module (ui/src/chapterpanel.ts) that margin notes (row 40, NB8) reuse (test at_verse_chip_popup).

Open questions

  • Two Scripture blocks side by side (44): the form in the file for a pair of columns.
  • Fonts (row 31): which reading serif already shipped joins Default and Serif; no font downloads.
  • Board view (47d): dragging a card to another folder's column moves the page; is that wanted, or is a board only for reading?
  • Nesting and the Shelf: folders in folders, pages in pages, how a nested page shows its folder's color, references to pages, and the Shelf move to their own design in the library folder (proposed next). Row 26 stays as drawn until then.
