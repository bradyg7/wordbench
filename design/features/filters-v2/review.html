Decisions, 2026-11-22

  • 2026-11-22, the person. Scrap the old Filters design (Direction B) and design filters again to fit the Notebook.
  • 2026-11-22, the lead (file form, by the person's standing go-ahead of 2026-11-21). A filter is kept in the list's ``` `view ``` fence as one line each, under the command line and the other options: filter: PROPERTY is VALUE[, VALUE…], filter: PROPERTY is not VALUE[, …], filter: PROPERTY is empty, filter: PROPERTY is not empty, and for dates filter: Edited|Written today|last 7 days|last 30 days|last year. Several values on one line match any of them; several lines must all match. Plain words, one line each, so the file reads like the chips and other Markdown tools show it as text; it extends NB14's name: value option lines rather than adding a second form. A line that names a property or value no longer present is kept as written (row 12).
  • 2026-11-22, the lead. Chips apply at once; there is no Apply button and no pending state (the old design's Apply, Close and pending edits are dropped). Undo of a filter change is the chip's ×.
  • 2026-11-22, the lead. Folder is offered only when the list's pages come from more than one folder; a list that names one folder already is that folder.
  • 2026-11-22, the lead. The Library lists' chips (rows 13–15) live only in the window for the life of the tab (as the side list's choices do today); only a list in a page keeps its filters on disk.

Should each take the same chips in a later round (lead's leaning: yes, one round each, in the map's priority order), or stay as built?

  • Any of / all of. Round 1 has every chip must match, values within a chip any. Is a whole "match any chip" switch wanted (Notion's filter groups), or is that more than a study needs?
  • Library map words. This folder uses two words the map does not list yet: filter (a picked condition shown as a chip on a list) and page property (a column kept in a page's front matter, from NB14). Proposed map change: add both to the words table. The old word "applied value" is retired with Direction B.
